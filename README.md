# EL-PDF Viewer

> **Everyone's Lightweight PDF Viewer** — 一个不收费、无广告、不联网、不检测的 PDF 查看器。

## 为什么诞生了这个项目？

- **Adobe Acrobat**：你很难相信，在高价买断和低价订阅之间，竟然会有这么一家公司，选择了一个所有人都意料不到的答案：高价订阅。这种自毁名声的行为，无疑加速了用户他们脱离生态，全力寻找替代品。
- **WPS Office**：但凡听说过kingsoft的用户们都知道，k系软件有大量的功能收费（甚至于一些很基础的功能）；k系软件启动的速度都是偏慢，在中低端设备上的表现就更加逆天了。吃相难看不说，软件启动的同时还弹窗要求登陆。即使是专门优化的特供版本，内存占用偏高和UI卡顿的问题同样没有解决。
- **其他**：要么收费，要么广告，闹心的问题一个接一个，想要好好弄个PDF真的这么难吗？

**我们想要的只是：打开 PDF、看得清、翻得快、搜得到、不联网、不收费。**


## 当前功能

- ✅ 打开本地 PDF 文件（拖拽 / Ctrl+O）
- ✅ 多页连续滚动浏览
- ✅ 缩放 50%–400%（滑块 / 输入框 / Ctrl+滚轮）
- ✅ 页码跳转、键盘翻页（PgUp/PgDn，↑/↓ 微调）
- ✅ 纯离线运行，**零遥测、零上传、零账号**

## 技术栈

| 层级 | 选择 | 理由 |
|------|------|------|
| UI 框架 | **PySide6 (Qt 6)** | 原生性能、成熟稳定、LGPL v3 |
| PDF 渲染 | **PyMuPDF (fitz)** | 渲染极快、内存占用低、MIT 协议 |
| 语言 | **Python 3.10+** | 易上手、生态丰富、贡献门槛低 |

## 快速开始

```bash
# 1. 克隆仓库
git clone https://github.com/yourname/EL-PDF.git
cd EL-PDF

# 2. 安装依赖（建议虚拟环境）
pip install -r requirements.txt

# 3. 运行
python main.py
```

> **打包发布**：后续会提供 `pipx install el-pdf` 与 GitHub Actions 自动构建的 `.exe` / `.AppImage` / `.dmg`。

## 键盘快捷键

| 动作 | 快捷键 |
|------|--------|
| 打开文件 | `Ctrl+O` |
| 放大/缩小 | `Ctrl+滚轮` / `+/-` |
| 适应宽度 | `Ctrl+0` |
| 上/下一页 | `PgUp` / `PgDn` |
| 微调滚动 | `↑` / `↓` |
| 跳转页码 | `Ctrl+G` (规划中) |
| 全屏 | `F11` (规划中) |

## 一些后记
一开始我并没有打算开发这个软件，因为修改过的acrobat本来是用的好好的。但是莫名其妙的有一天弹窗了，于是我把它删了换WPS。但是WPS在我家的低端电脑上表现的非常慢，再加上动不动就跳登录，这让我感到非常恼火。也迫使了这款软件的诞生。<br>
一个编辑器和阅读器，在我看来并没有联网的必要，**因为用户想用它做什么，一切均为用户的选择，开发者无权干涉**<br>
不需要联网，同样意味着**我们决不会收集任何信息**，各位开发玩家和用户大佬们都可以自由审查，拉取，自行编译。承诺的重量，代码会告诉所有人。<br>
开源的软件，自然也注定了它不需要任何反破解代码，因为不存在利益干涉，因为————**开发者即用户，用户即开发者**。开源也明确了这款软件————没有收费的可能<br>
没有广告，也绝不可能有广告。<br>
